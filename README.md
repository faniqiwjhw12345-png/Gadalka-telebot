# Gadalka-telebot
Инструменты:Python,BotFather,PytelegramBotAPI
как запустить: 
1)используйте версию 3.10,3.11,3.12,3.13,3.14 Python
2)установите Pycharm и библиотеку pyTelegramBotAPI
3)найдите в поиске Telegram @BotFather
4)отправьте команду /newbot и следуйте инструкциям, чтобы создать бота и получить API TOKEN,потом скопируйте токен
